Multiplateforme

Cette application est utilisable peu importe l'endroit où vous vous trouvez. Votre smartphone, tablette, ordinateur de bureau et ordinateur portable sera en mesure de pouvoir installer et utiliser ce programme, ce n'est pas une application web de poche, mais une véritable application client afin de fournir la meilleure expérience possible.

Hors ligne avant tout

J'ai été frustré par la plupart des logiciels de rédaction d'histoire que je trouvais puisqu'ils utilisaient tous des technologies web (ex : page web déguisé en application) qui semblent toujours rencontrer des problèmes lorsqu'ils sont utilisés hors ligne trop longtemps. Hammer a été conçu dans le but d'être entièrement fonctionnel en local, sans aucune connexion internet nécessaire, pour toujours.

Transparence des données

Vos données vous appartiennent. Ils ne sont pas stockés dans le cloud, ou dans une obscure base de données. Tout est stocké dans des fichiers humainement lisibles, utilisant uniquement des fichiers et des dossiers pour définir la structure du projet. Vous pouvez donc y jeter un œil par vous-même en naviguant dans vos fichiers. Si ce programme disparaissait aujourd'hui, vous serez en mesure d'interagir facilement avec vos données.

Synchronisation intelligente entre vos appareils

Vos données peuvent être synchronisées entre plusieurs appareils vous permettant de poursuivre l'écriture de votre histoire là où vous le souhaitez, sans avoir la crainte qu'une édition faite sur l'un de vos appareils n'en écrase une faite sur un autre.

Synchronisation optionnelle et auto-hébergée

La synchronisation est entièrement optionnelle, vous pouvez installer le client et l'utiliser sur votre appareil sans aucune action supplémentaire, ou vous pouvez installer un serveur pour la synchronisation entre vos appareils.
